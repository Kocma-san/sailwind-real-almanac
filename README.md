# sailwind-real-almanac

Companion almanac for Sailwind’s [Realistic Skies](https://github.com/KingCam77/Realistic-Skies) mod.

Web helper for celestial navigation when **Star Type = Real**: GHA Aries + star SHA/Dec for the community [Desmos LOP](https://www.desmos.com/calculator/dml4fdrber) calculator.

Not affiliated with Realistic Skies — fan companion tool.

## Use

Open [index.html](index.html) in a browser, or use GitHub Pages once published.

## Requires

- [Realistic Skies](https://github.com/KingCam77/Realistic-Skies) (Sailwind mod)
- [Desmos Line Of Position](https://www.desmos.com/calculator/dml4fdrber)
